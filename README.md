# Singapore Resale Flat Price Prediction

An academic machine-learning project focused on estimating Singapore resale flat prices using property information and comparing regression models.

## Project Overview

This project explores Singapore resale-flat transaction data, prepares it for machine learning, and compares different regression models to estimate resale prices.

## Models

- Decision Tree Regressor
- Random Forest Regressor
- XGBoost Regressor

## Evaluation Metrics

- R² Score
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)

## Project Workflow

1. Load and explore the resale-flat dataset.
2. Clean and prepare the data for modelling.
3. Train Decision Tree, Random Forest, and XGBoost models.
4. Compare model performance using evaluation metrics.
5. Save the trained model and encoders for future use.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Dataset

Singapore HDB resale-flat transaction data.

Dataset reference:
https://github.com/noghte/datasets

## Project Status

Academic project covering data preparation, regression modelling, and model evaluation.

## Disclaimer

Predictions are estimates based on historical data and model inputs. They are not official property valuations.
